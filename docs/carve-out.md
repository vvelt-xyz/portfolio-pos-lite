## 証明一文

小規模飲食向け Web POS として、フロア起点の接客（案内→注文→提供→会計）と、設定の深さが伝わる業務アプリを、WELT ブランドの公開デモで示せる。

## 帯

**B 現場コア**（本体オペは本番相当の厚み）。  
スタックを本番同系統（Next + Firebase デモ用）まで寄せる場合は着手時に **C** へ上げてよい。当面の完成定義は B（品質・機能の厚さ）。C は技術宿主の選択。

## 秘匿リスト

**なし**（2026-10-27 採用）。  
機能を意図的に劣化させない。守るのはデータ／クライアント／秘密と、設定の永続改変のみ。

## 含める（ほぼ劣化なし）

本番 MVP 相当の主要機能をリビルドする（シードデータ・架空店・WELT ブランド）。

- フロア俯瞰（空席／接客中、バッジ）
- テーブル接客（人数・メモ・注文・追加）
- テイクアウト起票
- 注文（追加・取消・数量・提供前／済）
- 提供コンソール
- 会計（支払手段、未提供時確認、税込の基本機微）
- 本日集計の見え方（簡易で可）
- 設定・メニュー・税率・端数・フロア配置など → **Inspect のみ**（UI は本番相当、保存は無効またはセッション限り）

## Inspect

設定まわり全般。デモバナーで「閲覧のみ／ポートフォリオ用」を明示。

## 必ず除外

- 本番・顧客の実データ、本番 Firebase／秘密
- クライアント店舗名・ロゴ・住所・固有コピー
- 本番 Hosting／ドメイン接続
- 決済本番キー・カード情報
- HW レシート実機必須の部分（方針は capabilities で可）

## アピールと証拠

| 主張 | 証拠 |
|---|---|
| 現場オペが回る | Operate |
| 設定・レイアウトの深さ | Inspect |
| データ構造の緻密さ | コード + `docs/`（必要なら capabilities） |
