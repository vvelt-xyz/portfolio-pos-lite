# POS Lite — 説明文（貼り付け用）

## 一行

小規模飲食向け Web POS のコア動線（フロア案内 → 注文 → 提供 → 会計）を、ブラウザ完結のデモとして公開したもの。

## 短文（3〜5行）

飲食店の現場オペレーションを想定した Web POS のショーケースです。席の案内、注文、キッチンへの提供キュー、会計までの一連を TypeScript / React で実装しています。ポートフォリオ用の薄い再実装で、本番店舗システム（`05_POSsystem`）のソースそのものではありません。認証やクラウド DB は含めず、動作確認しやすいよう localStorage で状態を保持します。

## 技術タグ

`TypeScript` `React` `Vite` `クライアント状態` `業務 UI`

## 含まないもの

- 本番 Firebase / 顧客店舗データ
- レシート実機印刷・インボイス詳細・権限ロール
- 本番と同規模のドメインモデル
