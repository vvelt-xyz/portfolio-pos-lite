# WELT POS（ショーケース）— 説明文

## 一行

小規模飲食向け Web POS のフロア起点オペ（案内→注文→提供→会計）と、設定の深さを WELT ブランドの公開デモで示す。

## 短文

飲食店の現場を想定した Web POS のショーケースです。席の案内、人数・メモ、テイクアウト、注文の追加・取消・数量、キッチン提供、支払手段つき会計、本日集計までを TypeScript / React で実装しています。設定（税率・メニュー・フロア配置）は本番相当の項目を画面で確認できますが、公開デモでは閲覧のみです。本番店舗システムとは別リポのリビルドで、顧客データは含みません。© 株式会社WELT

## 技術タグ

`TypeScript` `React` `Vite` `業務UI` `税込カタログ` `シードデモ`
