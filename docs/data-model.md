# データモデル（ショーケース）

公開デモの構造証拠。本番 `05_POSsystem` の写しではなく、同等の関心事を薄い形で再現している。

## 層

| 層 | 内容 |
|---|---|
| Settings | 税率・端数・税込フラグ・店舗表示名 |
| Catalog | メニュー（税区分）・席（種別・定員・グリッド） |
| Ops | Session（席 or TO・人数・メモ・明細状態機械） |
| Sales | 会計確定（支払手段・合計・表示 ID） |

## セッション ID

店舗・営業日ごとの連番イメージ: `YYYYMMDD` + 3 桁（デモはブラウザ内 `daySeq`）。

## 明細状態

`draft` → `queued` → `served`（または `cancelled`）。会計は原則提供完了後。未提供ありは確認チェック必須。

## 永続化

デモ: `localStorage`（キー `portfolio-pos-lite-v2`）。営業日が変わると Ops/Sales をリセットしカタログ設定は維持。
